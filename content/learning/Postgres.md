
- Type of 'relational' database 
- Basic unit is tables

1. Select Data from a single table
2. WHERE - used for basic filtering based on values in the database

Quirks:
- `NULL` is a special data type. It is not 0. It is incomparable and therefore omitted filtering.  
- Values: 'single quote'
- Identifiers: "double quotes"

Concepts:
- "Upsert" - an update and insert at the time. You have to allow it with ON CONFLICT specifically. 

Joins:
- Used to "combine" rows from two or more tables
- Operate on two tables
